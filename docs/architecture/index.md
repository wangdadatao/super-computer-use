# 架构 文档目录

> 上级目录：[工程文档](../index.md)

## 范围

本分类拥有 **系统结构层面** 的知识：进程与模块边界、层间契约、核心算法
（元素身份、收敛判定）、基础机制（按应用知识），以及跨层的状态生命周期
（会话、快照与令牌）。

不在此分类：具体协议的字段定义（属于[接口](../interfaces/index.md)）、
术语定义（属于[领域](../domains/index.md)）、设计取舍的理由（属于[决策](../decisions/index.md)）。

## 文档

- [系统总览](system_overview.md)：四层分层、进程模型与跨平台抽象。读取时机：新增模块、改动进程边界、评估跨平台移植成本时。
- [策略与审批](policy_layer.md)：动作准入判定、审批作用域、拒绝类目。读取时机：改动准入逻辑、增加拒绝类目、实现审批界面时。
- [会话与控制租约](session_and_lease.md)：会话状态、目标绑定、串行化、后台与接管两种模式。读取时机：改动会话生命周期、处理清理、实现接管显示时。
- [元素身份](element_identity.md)：稳定元素身份的构造与匹配算法。读取时机：改元素寻址、处理快照漂移、实现重试逻辑时。
- [快照生命周期](snapshot_lifecycle.md)：快照、版本令牌与坐标令牌的状态迁移。读取时机：改动状态读取路径、处理失效上报时。
- [动作收敛与等待](action_convergence.md)：稳定信号、有界观察窗口、三态判定。读取时机：实现效果回报、调优等待策略、排查空操作误报时。
- [按应用知识注入](app_knowledge.md)：针对特定应用的先验知识及其投递时机。读取时机：新增应用知识、讨论知识边界时。
- [虚拟指示层](virtual_indicator.md)：屏幕上的可见反馈、截图排除、执行模式区分。读取时机：实现用户可见反馈、改动截图管线、排查「截图里多出东西」时。
