# ADR-0018 快照内的短标签寻址

- **状态**：已接受
- **日期**：2026-10-19

## 背景

v1 的元素表用 `[AXButton#129]` 这样的句柄寻址。句柄是权威的，但对模型有两个问题：

1. **数字不直观。** 模型要在长表里记住 `#129` 是搜索按钮，容易看错行；短标签更像
   Vimium 的 hint mode，选起来更稳。
2. **没有几何信息。** `AXNode.frame` 已经被原生层读取，但元素表没有输出；模型无法把
   元素和截图上的位置对上，也无法为后续的截图叠加做准备。

真实应用验证（网易云，CEF）证明 AX 路径可用，但也暴露了“模型要在一棵 1500 元素的树里
找目标”的成本。Vimium 式“给可交互元素一个短编号”能把这步变成选择题。

## 决策

### 1. 每次读取分配短标签，标签只属于本次快照

标签是**句柄的别名**，不是新的身份：

- 句柄仍然是路径解析的权威部分，跨工具、跨动作保持一致；
- 标签在快照内唯一，**不跨令牌**；结构变化后旧标签失效，与句柄的失效规则相同；
- 标签大小写不敏感，方便模型把 `A` 写成 `a`。

### 2. 只给“可交互”元素分配

- 角色白名单：按钮、链接、文本输入、搜索框、复选、单选、下拉、菜单项、标签页、
  滑块、步进器、展开三角等；
- 另外读取 `AXGroup`/`AXCell`/`AXRow` 的 `AXActionNames`，声明了 `AXPress` 的也标；
  外层容器和内部控件都可点时只标控件，避免同一区域叠两个标签；
- 跳过 `enabled=false`、零宽/零高、没有 frame 的元素；
- **按树先序分配**（不是按屏幕坐标排序）：窗口移动不改变标签，令牌复用时标签稳定；
- 标签用 `a..z, aa..az, ba..`；一次最多 300 个，超出的元素仍可用句柄寻址。

角色白名单是近似，不是“可点击”的完整判断；`AXActionNames` 补上了网页侧栏/表格行这类
“角色是分组但支持 `AXPress`”的容器。仍可能漏掉自绘控件，也仍可能出现“声明了 `AXPress`
但应用不响应”的假阳性（网易云左侧栏就是这样）。宁可漏标，不要给静态文本发标签。

### 3. 元素表输出标签与 frame

```
[a] [AXButton#129] "search" frame=(120,40,24,24)
[b] [AXTextField#132] value="" frame=(150,40,300,28)
```

`frame` 的单位是屏幕点，显示时取整；它只用于阅读与后续截图叠加，**不参与动作定位**。
动作仍然沿路径核对元素，不按坐标点击。

### 4. 四个动作工具都接受 `label` 或 `handle`

`click`、`type_text`、`press_key`、`set_value` 的目标参数改为二选一：

- 给 `handle`：与之前完全一样；
- 给 `label`：会话在快照里查出句柄，再走同一条策略 → 令牌 → 核对 → 投递 → 观察路径；
- 两个都给或都不给：参数错误，不做优先级推断。

标签解析不跳过策略检查，也不改变令牌语义。未知标签返回 `element_gone`，
旧令牌的标签返回 `stale_snapshot`。

### 5. 不改线协议

标签与 frame 都在 Core/MCP 层生成：`AXNode.frame` 已经在线协议里，标签是快照的派生数据。
线协议仍是 v5，原生层不需要知道标签。

## 取舍

**接受了“读取动作名”的代价。** 只对 `AXGroup`/`AXCell`/`AXRow` 调用 `AXUIElementCopyActionNames`，
避免为整棵树翻倍；仍可能漏掉其他角色的自绘控件。

**接受了“AXPress 可能是空操作”的现实。** 网易云左侧栏声明了 `AXPress`，标签能点，但应用不响应
（`noOpSuspected=true`）。这不是标签层能修的；需要坐标点击或应用专用适配。标签只负责“选目标”，
不保证每个目标都接受无障碍动作。

**接受了“标签会随结构变化重排”的代价。** 这是令牌失效语义的直接结果，不是缺陷。
模型必须在每次重读后使用新标签，和句柄的规则一致。

**接受了“标签占一点输出长度”的代价。** 每行多 2~4 个字符，换取模型选目标的稳定性；
300 个标签的上限防止长表被标签淹没。

**没有做截图叠加。** 标签先以文本形式落地；截图、叠加与坐标动作是后续能力，
复用同一套 `label + frame`，不需要重新设计寻址。

## 后果

- `ElementTable` 输出 `[a]` 与 `frame=`，并提供 `labels` 供后续截图叠加；
- `DesktopSession` 增加标签解析，四个动作工具接受 `label`；
- 标签在单元测试、MCP 测试与网易云 3.1.12（CEF）上验证；左侧栏能标出并解析到 `AXGroup`，
  但 `AXPress` 是空操作，坐标点击仍待补；其他真实应用待补；
- 不改线协议、不改动作语义；截图叠加与坐标点击仍待后续 ADR。
