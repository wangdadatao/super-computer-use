# 决策 文档目录

> 上级目录：[工程文档](../index.md)

## 范围

本分类拥有 **架构决策记录（ADR）**：影响系统长期形态、且未来可能被重新质疑的取舍。
每条 ADR 记录背景、决策、取舍与后果。

不在此分类：当前行为的描述（属于[架构](../architecture/index.md)等）、实现细节。

## 文档

- [ADR-0001 无障碍树优先，视觉坐标为兜底](adr_0001_accessibility_first.md)：确定主寻址路径及其代价。读取时机：讨论是否支持纯视觉方案、或处理无障碍树质量差的应用时。
- [ADR-0002 用 code mode 作为 agent 接口](adr_0002_code_mode_surface.md)：工具面形态的选择。读取时机：增删 agent 侧工具、讨论调用可观测性时。
- [ADR-0003 失效检测作为协议契约而非调用约定](adr_0003_snapshot_token_contract.md)：令牌机制与拒绝执行的取舍。读取时机：改动状态读取路径、讨论是否放宽令牌要求时。

- [ADR-0005 平台顺序：macOS 优先，Linux 后续](adr_0005_macos_first_linux_later.md)：平台支持顺序与跨平台抽象的先期成本。读取时机：讨论支持新平台、或质疑抽象层必要性时。

## 编号约定

新增决策从 **ADR-0007** 起顺序编号。文件名格式 `adr_<四位编号>_<短横线省略的描述>.md`。

## 关于外部实现

本项目的多项决策来自对两套已发布实现的分析：OpenAI 的 **Codex Computer Use**
与 xAI / Anysphere 的 **Grok Bot Computer Use**。相关 ADR 会引用观察到的具体机制
作为背景依据。

只借鉴设计模式与协议思想，不复制任何代码或专有实现。
