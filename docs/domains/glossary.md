## 无障碍与平台

**无障碍树（AX tree, accessibility tree）**
操作系统暴露的界面结构。每个可交互控件是一个节点，带角色、名称、
值和其他属性。macOS 通过 AXUIElement API 提供。

**树变更通知（tree change notification）**
平台在无障碍树发生变化时发出的事件。SCU 用它作为收敛判定的
首选信号，因为它不需要轮询。

**应用目标（app target）**
一个正在运行的桌面应用的一个窗口。SCU 的两个目标类型之一。

**页面目标（tab target）**
一个浏览器标签页。与应用目标共享同一套操作面。

**目标（target）**
应用目标和页面目标的统称。SCU 的一切操作都作用在某个目标上。

## 寻址

**元素引用（element reference）**
调用方持有的、指向某个界面控件的值。由[元素身份](../architecture/element_identity.md)
生成，编码为字符串（见[元素寻址](../interfaces/element_addressing.md)）。

**身份指纹（identity fingerprint）**
由 role、identifier、title、结构路径等稳定字段算出的哈希值。
同一控件的指纹在界面变化前后应保持不变。

**结构路径（structural path）**
从窗口根节点到目标节点的父链，记录每级的 role 和同级序号。
在缺少 identifier 时作为指纹的退化依据。

**匹配结果（match result）**
用指纹在当前快照中定位元素的结果，取 `stable`、`changed`、
`inferred`、`missing`、`ambiguous` 之一。

**引用形式（reference form）**
绑定目标时调用方给出的标识方式：运行时标识、进程与窗口标识、
应用标识、显示名称、或 URL。明确程度依次递减。

## 状态与有效性

**快照（snapshot）**
一次对无障碍树的读取，以及读取时刻的树结构。快照带版本令牌。

**快照令牌（snapshot token）**
标识快照版本的凭证。树未变化期间有效，可跨多次动作使用。

**坐标令牌（coordinate token）**
协议字段名为 `geometryToken`。标识截图几何基准的凭证。窗口几何未变期间有效。
文中一律使用「坐标令牌」，代码与协议定义中使用 `geometryToken`。

**失效（stale）**
令牌不再可用。失效的动作请求会被拒绝，而不是执行。

**失效类别（staleness kind）**
失效原因的分类：树变化、窗口变化、目标切换。

**画布（canvas）**
坐标的基准平面。固定尺寸、原点在左上角。坐标值始终是画布坐标，
不是屏幕坐标，两者不可混用。见 [ADR-0008](../decisions/adr_0008_coordinate_canvas.md)。

## 策略与准入

**策略层（policy layer）**
决定动作是否允许执行的层。位于接入层与协议层之间，
每个动作都必须经过它，没有旁路。

**动作准入（action admission）**
策略层对一个动作给出的判定过程与结果。

**准入结论（admission verdict）**
准入判定的三态结果：**允许** / **需确认** / **拒绝**。
三态必须区分：「需确认」可恢复，「拒绝」不可协商。

**策略拒绝（policy denial）**
动作因策略层判定而不执行。调用方**不应重试**——
这与[失效](#状态与有效性)导致的拒绝含义不同，后者应重读状态后重试。

**审批作用域（approval scope）**
审批结果的有效范围：
**会话级**（当前会话结束即失效）与
**持久级**（跨会话保留，用户可撤销）。

**拒绝类目（denial category）**
不可协商的拒绝条件，命中即拒绝且不提供用户覆盖途径。
用于后果不可逆的场景（如操作终端、访问凭据存储）。

## 动作

**动作（action）**
对目标元素的一次操作：点击、输入、按键、滚动、拖拽、设值、调用次要动作。

**动作效果（action effect）**
动作执行后服务端回报的可核对外部观察：树是否变化、目标元素的属性是否变化、
焦点是否被夺走、是否疑似空操作、是否已收敛。

**空操作（no-op）**
动作被成功投递，但界面没有产生任何可观测变化。

**收敛（convergence）**
目标界面进入稳定状态。判定依据是可观测信号
（树变更通知停止、加载状态结束），而非固定延时。

**收敛窗口（convergence window）**
动作后观察目标是否稳定的有界时间区间。由静默阈值与总上限共同界定。

**静默阈值（quiet threshold）**
持续多久无变化视为稳定。取值需跨过单帧渲染抖动，又不至于让用户等待。

**未收敛（not converged）**
在收敛窗口内未观察到稳定。**这不是"没生效"，而是"还不知道"**——
两者对调用方的含义不同。

**次要动作（secondary action）**
元素通过无障碍接口暴露的、点击之外的动作，例如展开、显示菜单、取消。
需要元素显式声明支持。

**剪贴板句柄（clipboard handle）**
代表一份剪贴板内容快照的凭证，不是对系统剪贴板的持续引用。
用句柄写入后可恢复原内容，句柄可重复使用，需显式释放。

## 会话

**会话（session）**
服务进程内一段连续的交互状态：当前目标、当前快照、令牌签发记录、
会话级审批授权。会话是令牌的作用域——换目标意味着旧令牌全部失效。

**串行化（serialization）**
同一会话内的动作严格按序执行，收敛窗口包含在串行段内。
这是正确性要求而非性能优化。

**控制租约（control lease）**
对系统输入控制权的独占占用。见**执行模式**。

**执行模式（execution mode）**
SCU 当前的运作状态，两种：

- **后台操作**：真实指针不动，用户可以同时使用电脑
- **接管显示**：真实指针可被移动，用户不能同时使用电脑

两种模式的风险等级不同。**升级必须显式，释放可以自动**——
这个不对称是刻意的。

## 用户可观测

**虚拟指示层（virtual indicator layer）**
屏幕上的可见反馈，用来显示 SCU 正在操作哪里。它是 AX 寻址的必要补偿：
通过无障碍接口操作不会移动真实指针，没有指示时界面变化对用户不可见。

**操作点指示（action point indicator）**
指示层的一个元素，标记当前动作的目标位置。对元素寻址的动作，
它定位在元素的无障碍几何上，而不是鼠标位置。

**目标窗口指示（target window indicator）**
指示层的一个元素，高亮当前绑定的目标窗口。解决"agent 在操作哪个窗口"
在多窗口场景下难以判断的问题。

**自建窗口登记表（own-window registry）**
SCU 记录自己创建的窗口（指示层、审批提示）的登记表。
它是单一事实来源，供截图排除与元素表排除共同使用，
避免两条路径不一致。

## 接入与服务

**接入层（agent surface）**
把 agent 请求翻译为动作请求的那一层。当前形态是 MCP stdio 服务。

**原生层（platform backend）**
直接调用操作系统 API 的薄封装，运行在独立 sidecar 进程中。
除读取平台事实与注入事件外，它还持有自建窗口登记表，
供截图排除使用。

**协议版本（protocol version）**
跨进程边界的兼容性标识，单调递增的整数。
不匹配时拒绝建立会话，不做隐式兼容。见
[ADR-0012](../decisions/adr_0012_protocol_versioning.md)。

**应用知识（app knowledge）**
针对特定应用的、无法从无障碍树读出的行为特征。
在首次绑定该应用时随状态读取结果一同投递给模型，每会话一次。
