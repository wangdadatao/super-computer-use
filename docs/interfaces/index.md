# 接口 文档目录

> 上级目录：[工程文档](../index.md)

## 范围

本分类拥有 **对外契约**：agent 侧的工具面与运行时行为、目标发现与绑定规则、
元素寻址格式、编辑类操作的语义、动作效果回报与错误返回的结构。

不在此分类：内部模块间的调用关系（属于[架构](../architecture/index.md)）、
设计理由（属于[决策](../decisions/index.md)）。

## 文档

- [协议总览](protocol_overview.md)：会话 API 的完整面与调用约定。读取时机：写 agent 集成、MCP 客户端或测试夹具时。
- [原生层线协议](native_wire_protocol.md)：协议层与原生层之间的帧格式、消息目录、握手与连接生命周期。读取时机：改动两进程间的通信、增删原生层请求、排查握手或版本错配时。
- [MCP 接入面（只读档与动作档）](mcp_surface.md)：`scu mcp` 的工具目录、元素表输出、错误通道、JSON-RPC 处理与进程清理。读取时机：改动 MCP 工具、接入新的宿主、排查 stdout 污染或残留进程时。
- [运行时契约](runtime_contract.md)：code mode 的执行模型、输出通道、沙箱边界、超时与重置。读取时机：实现或对接运行时、处理超时与取消时。
- [目标发现与绑定](target_discovery.md)：应用与页面标签页的枚举、引用形式、歧义处理。读取时机：实现发现接口、处理绑定失败、排查「绑错了目标」时。
- [元素寻址](element_addressing.md)：元素引用的格式、解析规则与句柄生命周期。读取时机：实现或消费元素引用时。
- [编辑类操作语义](edit_semantics.md)：文本写入的三条路径、选择消歧、剪贴板快照、拖拽与修饰键。读取时机：实现输入类动作、处理剪贴板副作用时。
- [错误与拒绝](error_taxonomy.md)：错误码表、可重试性映射、成功与失败的边界。读取时机：写重试逻辑、实现错误返回、排查「拿到意外结果」时。
