# 运维 文档目录

> 上级目录：[工程文档](../index.md)

## 范围

本分类拥有 **运行与维护** 知识：开发环境搭建、系统权限、测试与验证方法。

不在此分类：架构设计（属于[架构](../architecture/index.md)）、部署形态决策（属于[决策](../decisions/index.md)）。

## 文档

- [本地环境](local_setup.md)：开发环境依赖与首次运行步骤。读取时机：在新机器上搭建开发环境时。
- [macOS 权限](permissions.md)：辅助功能与屏幕录制权限的要求、检测与排障。读取时机：遇到权限拒绝、或实现权限检查逻辑时。
- [测试策略](testing.md)：如何验证元素身份、快照语义与动作效果。读取时机：新增测试、或评估改动影响面时。
