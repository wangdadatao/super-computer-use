# 令牌的拒绝行为与重读成本（2026-10-19）

按 [ADR-0013](../docs/decisions/adr_0013_p0_vertical_slice.md#gate_revision_2026_10_19) 的
2026-10-19 追加记录第 3 条执行。这是**度量记录**：四个令牌用例的语义已在
[2026-10-18-fixture-validation.md](2026-10-18-fixture-validation.md) 里记录为成立，
本次补的是误拒与重读成本的数据。

## 采集环境

| 项 | 值 |
| --- | --- |
| 系统 | macOS 26.6.2，arm64 |
| 时间 | 2026-10-19 17:10 CST |
| 工具 | `scripts/measure_token_reject.py --rounds 8`（提交 `211de36` 的工作区） |
| 宿主 | pi agent 会话（launchd 下的 `node`，pid 7642）；`scu permissions` 退出码 0（辅助功能已授予） |
| 夹具 | 真实 `scu-fixture`，两个独立的 `scu mcp --actions` 会话（各自的 `DesktopSession`） |
| 重复 | 每项连续 8 轮 |

两个会话是必要的：一个会话看不到另一个会话造成的界面变化，所以 B 的改动对 A 而言等同于"应用自己变了"。
这也正是 ADR-0015 的路径核对要处理的情形。

## 方法

脚本自己启动夹具，按 pid 等界面可读（不依赖 `list_apps` 注册），然后：

| 指标 | 构造 |
| --- | --- |
| A 无外部变化时重复动作 | 读一次令牌，用同一令牌连续点击 `NoOp`（不改任何界面） |
| B 外部值变化后动作 | 会话 A 读令牌；会话 B 点击 `Increment` 改标签文字（路径不变）；A 再用旧令牌点 `NoOp` |
| C 外部结构变化后动作 | 会话 A 读令牌；会话 B 点击 `AddRow` 加一个兄弟节点；A 再用旧令牌点 `NoOp` |
| D 自身点击后的令牌失效 | 用同一令牌连点两次 `Increment`（第一次改值，第二次用已失效的令牌） |

## 结果

| 指标 | 轮数 | 结果 |
| --- | --- | --- |
| A 无外部变化时重复动作 | 8 | 被拒 **0** 次；`noOpSuspected=true` 8/8 |
| B 外部值变化后动作 | 8 | 被拒 **0** 次 |
| C 外部结构变化后动作 | 8 | 被拒 **8** 次（`stale_snapshot`） |
| D 自身点击后的令牌失效 | 8 | 第一次点击后令牌失效 8 次；第二次仍通过 **0** 次；重读 8 次 |

## 观察

1. **无外部变化时不误拒。** 同一令牌连续 8 次动作全部成功，空操作判定也一致（8/8）。
2. **值变化不误拒。** 另一会话改变标签文字后，本会话的旧令牌仍能动作。结构摘要包含 `value`，
   但动作时的核对只看路径与核对键（role、title、identifier 等），两者口径一致。
3. **外部结构变化后全部被拒。** 目标本身没变（`NoOp`），只是同一容器多了一个兄弟节点，
   旧令牌在动作时被 `stale_snapshot` 拒绝。这是 [ADR-0015](../docs/decisions/adr_0015_handle_resolution_by_path.md)
   预期的保守取舍；8/8 是这个构造的必然结果，**不代表真实界面的发生频率**。
4. **自身改值点击总使令牌作废。** `Increment` 改变标签文字，值进结构摘要，令牌 8/8 失效，
   下一次用同一令牌 8/8 被拒。也就是说，**每次会改值的点击之后都要重读**。这是"每动一步重读一次"
   的固定成本，[ADR-0014](../docs/decisions/adr_0014_positioning_ai_usability.md) 的可用性度量应把它算进去。
5. **没有发现漏报或类别错报。** 所有拒绝都是 `stale_snapshot`，没有该执行而执行的情况。

## 限定

- 夹具不是真实应用；C 的比例是构造使然，不是频率估计。
- 每项 8 轮，样本小；只覆盖 `AXPress`，没有输入与坐标动作。
- **真实应用里"界面自己变了"的发生频率与误拒率仍未度量**：它决定成本的真实大小，不决定机制是否正确。
  这项并入"第三方应用 `AXPress`"与"经宿主调用 `click`"两个未验证项。
- 采集过程中发现的脚本缺陷（句柄正则漏掉缩进行）已修复（提交 `211de36`）；它只影响测量工具，不影响产品代码。

## 结论

令牌的拒绝行为符合 ADR-0015 的设计：**无外部变化与值变化都不误拒，外部结构变化按设计拒绝，
改值点击后需要重读**。令牌机制在受控环境上没有漏报与类别错报；
真实应用上的成本大小留作 P0 之后的观察项。
